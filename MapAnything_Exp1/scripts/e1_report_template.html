What we tested

Each test is one scene, 10 photos, rebuilt by MapAnything with hints. Every wrong-hint run is compared with the same scene's runs with no hint of that kind (the "floor") and with the correct hint (the "ceiling"). Scenes and their size L: {{L_LIST}}.

How to read "benefit lost". 0 = as good as the correct hint, 1 = as bad as having no hint. Above 1 means the wrong hint is worse than no hint. It is a ratio, so when the correct hint barely helps it can get very large from a small change; the tables also show the plain difference.

As preregistered: "benefit lost"

The plan's own headline measure. It divides by how much the correct hint helped, so for lens and depth hints, where the correct hint helps very little, it swings wildly. Those panels have huge error bars, and the per-scene map shows random-looking stripes. The decision rules use it together with the 5% minimum effect; the figures above show the same comparisons in a stable form.
